# 家計簿：収支計算・支払い計画 要件

## 目的
`家計簿.xlsx` の「分割シート」および各「○月分」シートをもとに、リボ払い・分割払い・固定費・電気・ガス・水道などの月々の経費を一元管理し、毎月の収支と今後の支払い計画を把握できるようにする。

## 対象データ
- 「分割シート」
  - 分割払いの項目
  - 支払額
  - 残り回数
  - 残額
  - 完済予定
- 各「○月分」シート
  - 「リボ」と記載されている箇所を抽出
  - リボの利用額・支払額・残高などを整理
- 月々の経費
  - 固定費（家賃、通信費、保険、サブスク等）
  - 電気
  - ガス
  - 水道
  - その他の生活費・変動費

## 支払い計画
### 1. 個別の支払い計画
各支払いについて、以下を管理する。
- 支払項目
- 支払月・支払予定日
- 予定支払額
- 実際の支払額
- 差額
- 支払い後残高
- 残り回数
- 完済予定
- 支払状況（予定・支払済み・完済等）

### 2. 月ごとの合計額
月単位で以下を集計する。
- 固定費・生活費
- 電気・ガス・水道等の経費
- リボ払い合計
- 分割払い合計
- その他の支払い
- 月間支払合計
- 収入
- 月末残額（収入 − 月間支払合計）

### 3. 支払いが次々に終了する状況の可視化
支払いが完済するたびに、その支払いを以降の月から除外し、毎月必要となる金額がどのように減少するかを確認できるようにする。

特に、以下を把握できるようにする。
- 各支払いがいつ終了するか
- 支払い終了後に毎月いくら負担が減るか
- 今後各月に最低いくら必要か
- 今後の支払い総額はいくらか
- 個別支払いごとの残額と、全支払いを合計した残額

## 自動更新要件
家計簿の各月シート等に実際の支払額が記入されるたびに、支払い計画側が連動して更新される構成とする。

入力した実績に応じて、少なくとも以下を自動更新する。
- 支払済み金額
- 支払い後残高
- 残り回数
- 完済予定
- 月別支払合計
- 今後必要な支払額
- 個別支払いの残額合計
- 全体の支払残額合計
- 月ごとの収支・残額

予定支払額と実際の支払額が異なる場合にも対応できるよう、「予定」と「実績」を分離して管理する。

## 更新後に確認したい情報
最終的に、以下が一目で確認できる状態を目指す。

### 個別
- 何の支払いが
- いつ
- いくら必要で
- あと何回・いくら残っていて
- いつ完済するのか

### 月別
- その月の固定費・生活費はいくらか
- 電気・ガス・水道等はいくらか
- リボ・分割はいくらか
- その月の支払い合計はいくらか
- 収入はいくらか
- 支払い後にいくら残るか

### 全体
- 今後の支払い総額
- 個別項目ごとの残額
- 支払いが終了する順番
- 支払い終了によって毎月どれだけ負担が減るか

## 実装方針
`家計簿.xlsx` の既存構成・入力方法を確認したうえで、既存データをなるべく壊さず、利用者が各月の実績額を入力するだけで支払い計画・収支計算が更新される構成を優先する。
