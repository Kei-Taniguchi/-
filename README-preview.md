# Codespaces preview

The app runs on Node.js 22 with `http-server` at `0.0.0.0:8080`. Dependencies are installed automatically and port 8080 is forwarded as HTTP with browser auto-open.

For an existing Codespace after `.devcontainer` changes, run **Codespaces: Rebuild Container** once. Then use **Open in Browser** on port 8080 if the browser does not open automatically.
