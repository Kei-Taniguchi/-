# Codespaces preview setup

Node.js 22 is provisioned automatically. Dependencies are installed with npm. The preview server listens on `0.0.0.0:8080`; port 8080 is automatically forwarded and configured to open in the browser.

If an existing Codespace was created before these settings changed, use **Codespaces: Rebuild Container** once. The Ports panel can then open port 8080 in the browser.
